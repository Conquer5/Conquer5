## 👨‍💻 About Me

Halo! Saya **Rafly Anugrah Syahputra**, seorang **Data Scientist yang berfokus pada AI Engineering dan Agentic AI Systems** dari **Universitas Negeri Surabaya**.

Saya tertarik membangun solusi berbasis data dan kecerdasan buatan untuk menyelesaikan permasalahan nyata — mulai dari pengolahan data, Machine Learning, dashboard interaktif, hingga pengembangan **LLM applications, RAG systems, AI Agents, dan intelligent automation**.

Saat ini saya juga mulai mengembangkan workflow AI yang lebih **agentic dan autonomous** menggunakan teknologi seperti **Hermes Agent, LangChain, Python, dan Node.js**.

* 📊 Mengolah dan menganalisis data menggunakan **Python** dan **SQL**
* 🧠 Mengembangkan model **Machine Learning** untuk prediksi, klasifikasi, dan analytical modeling
* 🤖 Membangun dan mengeksplorasi **LLM Applications, RAG, dan AI Agents**
* 🧩 Mengembangkan agentic workflow menggunakan **Hermes Agent** dan **LangChain**
* 🟢 Mengembangkan backend dan automation workflow menggunakan **Node.js**
* 📈 Membangun dashboard dan aplikasi data menggunakan **Streamlit**
* ⚙️ Membuat automasi menggunakan **Python, Node.js**, dan **Google Apps Script**
* 🗄️ Mengelola data menggunakan **PostgreSQL, SQLite, Excel**, dan **Google Sheets**
* 🌱 Terus mempelajari pengembangan sistem AI secara **end-to-end**
* 🎯 Berfokus pada solusi AI yang praktis, reliable, dan dapat digunakan untuk menyelesaikan masalah nyata
